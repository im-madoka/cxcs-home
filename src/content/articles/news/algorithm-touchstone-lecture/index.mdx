2025 年 11 月末，东南大学成贤学院综合楼阶梯多媒体大教室灯火通明、人潮涌动。由计算机协会（CXCS）策划发起、正式通过学校“第二课堂成长便签（PU）”系统立项为院级重点学术讲座的“算法试金石：从递推递归到动态规划”专题学术沙龙在此震撼开讲。讲座吸引了全校两百余名来自各个工科与经管院系的编程与算法爱好者踊跃到场。宽敞的大阶梯教室座无虚席，后排与两侧走廊临时加设了塑料长凳，连窗边都挤满了手捧笔记本记录要点的低年级同学，现场求知氛围空前热烈。

### 规范立项：院级权威学术活动开场

讲座伊始，电子与计算机工程学院指导教师孙丽老师受邀出席并发表了热情洋溢的开场致辞。孙丽老师对计算机协会长期以来坚持深耕底层算法训练、常态化组织牛客线上打榜的务实学风给予了充分肯定。她指出，动态规划不仅是全国大学生程序设计竞赛（ICPC）、蓝桥杯及各类国家级学科竞赛中拉开分数差距的核心压轴壁垒，更是考研计算机专业课乃至未来走向一线软件算法工程岗位必须跨越的思维高地。希望全体参会同学能够通过本次讲座，真正领会“以状态定义时空、用递推化解混沌”的数学美感与计算智慧。

### 阶梯拆解：从暴力搜索到记忆化优化的思维跃迁

随后，计算机协会核心技术骨干、蓝桥杯省一等奖得主陈昶元与算法部部长刘佳昊联袂走上讲台，展开了一场长达两个半小时的纯硬核思维拆解。为了让大一与零基础同学能跟上节奏，主讲人摒弃了晦涩难懂的公式堆砌，以人人皆知的经典问题“斐波那契数列”和“青蛙爬楼梯”作为思维切入点。

主讲团队首先在多媒体白板上实时绘制了朴素递归求解斐波那契数列的代码调用树。大屏幕上，随着层级加深，呈几何级数急剧膨胀的冗余计算分支以直观的红色树状图展现出来。陈昶元现场指出：“暴力的深搜递归之所以遭遇 $O(2^N)$ 的指数级时空爆炸，核心病根就在于极高密度的‘重叠子问题’。我们在无数次重复计算早已解决过的子状态。”

借此契机，主讲人自然而然地引出了“记忆化搜索”的核心哲学——利用一张哈希表或一维静态数组，将每一次计算过的中间状态妥善落盘，使得下一次调用可以直接 $O(1)$ 命中缓存。这一“以空间换取海量时间”的优雅思维转变，瞬间将原本不可承受的指数级灾难降维为平滑的 $O(N)$ 线性时间复杂度，引得台下在座同学频频颔首、茅塞顿开。

### 体系精讲：动态规划四步心法与五大经典模型

在完成了递推向动规的心理破冰后，刘佳昊进一步系统化提炼了破解一切动态规划问题的“四步通用心法”：

1. **状态定义**：明确数组下标 `dp[i]` 或 `dp[i][j]` 究竟代表何种物理或业务含义；
2. **状态转移方程推导**：寻找全局最优解与局部子结构之间的决策转移逻辑；
3. **边界与初始条件**：厘清最小平凡子问题的确切解，严防数组下标越界；
4. **求解顺序与空间压缩**：确定自底向上的拓扑填表方向，并适时运用滚动数组将二维空间开销压缩至一维。

随后，讲座进入了白热化的经典模型实战解构。主讲人深入剖析了五大高频竞赛模型：

- **背包体系**：从经典的 0-1 背包选与不选决策、完全背包的顺序遍历优化，讲到多重背包的二进制拆分技巧；
- **序列模型**：最长上升子序列（LIS）的动态规划推导以及利用贪心结合单调栈二分达到 $O(N \\log N)$ 的极致优化；
- **双串比对**：最长公共子序列（LCS）与编辑距离（Edit Distance）的二维矩阵状态推演；
- **区间与图论**：石子合并区间 DP 的枚举断点法以及树形 DP 在求解树的最长直径与最大独立集上的应用。

### 实战演练：现场手撕代码与学分闭环

为确保在座同学不仅“听得懂”，更能“写得出、调得对”，讲座现场设置了限时 15 分钟的在线测评手撕环节。主讲人在大屏幕上公开调出了牛客网竞赛系统中的精选实战题目。参会同学纷纷在自带的笔记本电脑上敲击起 C++、Python 或 Java 代码。

主讲人陈昶元与台下助教团队穿梭在过道之间，实时帮助遇到“时间超限（TLE）”、“内存超限（MLE）”或“段错误（SIGSEGV）”的低年级同学排查边界指针。伴随着倒计时推进，大屏幕后台测评系统连续弹出一道道“Accepted”绿色满分弹窗，整个多媒体阶梯教室响起了热烈的掌声，许多大一新生第一次真切体会到独立写出正确动态规划代码的巨大成就感。

讲座尾声，协会现场组织全体参会学子通过 PU 口袋校园移动端扫描专属签到二维码，严格核发了每人 0.1 分的第二课堂文体学分。同时，计算机协会竞赛部宣布，本周末牛客网常态化“贤者算经”算法小练习将无缝上线讲座配套的专项演练题单，帮助大家趁热打铁巩固讲座所学。

这场高标准、重落地、深层次的学术讲座，不仅在全校范围内刮起了一股攻坚核心算法的学习热潮，更向全校师生集中展示了计算机协会在专业教学反哺、学术氛围营造与学生自我赋能方面的成熟组织力量。
