## 为什么做它？

很多项目已经写完了，最后一步却卡在部署。CXCS Page 把连接仓库、安装依赖、构建和发布收进一条可以看懂的路径。

## 创建项目

把项目代码放进 GitHub 仓库，在 Page 中选择它。项目从这里开始有了自己的地址。

## 自动构建

平台会拉取代码、安装依赖并运行构建。每一次 Pull Request 都可以拥有独立 Preview。

## Preview 与正式发布

确认页面在手机、深色模式和真实内容下都工作后，再从 `main` 发布正式版本。
